# Открытые вопросы

Обновляй этот файл, когда ответ меняет план. Подтверждённое решение и ближайшее действие отражай в [CURRENT.md](CURRENT.md). Выбор трека 1 закрыт 9 ноября 2026 года, см. [PLAN.md](PLAN.md). Вопрос о черновике Figma закрыт в тот же день: источник правды для интерфейса — [UI-кит](design/ui-kit.md), Figma служит зеркалом.

| Вопрос | Зачем выяснять | Что можно сделать сейчас |
| --- | --- | --- |
| Нужны ли исходные данные сверх локальной копии? | Разрешённые названия и аннотации улучшат словарь запроса и позволят показывать реальные карточки локально; ссылки включат переход; интервалы событий дадут свежесть | Работать на копии и признаках из текстов. Если владелец разрешит, положить названия и аннотации с тем же псевдонимным `Id` в `data/local/`. Персональные поля, тексты уроков и цены не нужны |
| Достаточно ли проксировать уровень статей и документов стадией? | Уровень размечен только у курсов метками «Без опыта» и «С опытом»; у статей признак уровня нейтрален | Проверить на локальном прогоне, различает ли стадия вводные и углублённые статьи. При необходимости запросить разметку уровня |
| Как показать следующий шаг без оригинальных ссылок? | Влияет на демонстрацию и оформление платных карточек | Решение первого этапа: шаблон шага по формату и нейтральное действие «Отметить изученным» (PLAN.md, 3.6). Ссылки подключать только при отдельном предоставлении и разрешении |
| Будет ли демо развёрнуто публично или только локально в Docker? | Определяет аутентификацию, лимиты, хранение данных и условия нагрузочного прогона | План рассчитан на локальный запуск. При публичном развёртывании расширить проверки из PLAN.md, 7.2 |
| Допустимо ли использовать LLM для формулировки причин во втором этапе? | Влияет на ключи в комплекте, приватность и детерминизм | Первый этап без LLM. Для второго уточнить разрешённые поля и сервис |
| Где проверять Docker-сборку, если на машине разработки нет Docker? | Условие требует запуск через Docker, а локально доступны только Python и Node | Dockerfile, `compose.yaml`, `compose.data.yaml` и workflow `.github/workflows/docker-check.yml` готовы и проверены статически; `npm ci` для Alpine сымитирован, тесты прошли на Python 3.12, локальный запуск по README проверен из чистой копии. Нужен прогон workflow во внешнем репозитории, где содержимое `app/` лежит в корне, или `docker compose up --build` на машине пользователя |
| Входят ли в комплект внешнего репозитория PLAN.md и UI-кит? | Комментарии кода ссылаются на разделы PLAN.md и на `design/ui-kit.md`; без этих файлов ссылки висят. Видимый текст витрины на них уже не ссылается | Оставить ссылки: они связывают код с решениями в рабочей базе. При сборке комплекта либо положить `PLAN.md` и `design/ui-kit.md` в `docs/`, либо заменить ссылки нейтральными формулировками |
| Нужен ли красный в палитре интерфейса? | Пользователь не уверен в нейтральной палитре. Красный занят ошибками: баннер ошибки и ошибка поля | Снимки трёх вариантов экрана P01 на 1120 и 390 px лежат в `design/track1/preview/accent/`: текущая палитра, красный акцент, красная марка. Красный акцент делает баннер уточнения неотличимым от баннера ошибки, а ссылки-кнопки похожими на удаление. Рекомендация: оставить синий акцент, красный допустим только в марке или после получения фирменной палитры. Смена палитры — правка `tokens.css` и таблицы 2.1 UI-кита с повторной проверкой контраста и axe |
| Сопоставлять ли с темами остальные рубрики статей? | 20 рубрик, в которых 671 статья, не входят в группы тем; тема «Услуги» у двух курсов тоже без группы | Темы этих статей уже приходят из `ContentSettingsTopics`, покрытие 98,7 %. Новые рубрики добавляются правкой файла соответствия без кода, но меняют числа таблицы 2.3. Решить вместе с владельцем данных |
| Какой формат сдачи выбран и где будет проверка? | Влияет на доступ проверяющих и на то, нужна ли ссылка на первом слайде | Решение пользователя 10 ноября 2026 года: презентация не ждёт выбора формата. Поле ссылки на репозиторий на первом слайде остаётся пустым, пользователь заполняет его сам при сдаче. Порядок проверки на слайде одинаков для репозитория и архива: `docker compose up --build`, адрес `http://localhost:8000`, маршрут демонстрации из README. Чистый запуск комплекта перед сдачей по [руководству](guides/submission.md) |
| Доступна ли телеметрия для онлайн-эксперимента? | Определяет возможность измерить эффект на покупки и активные дни | План эксперимента в PLAN.md, 7.3; события и окно уточнить по [руководству](guides/evaluation.md) |
| Есть ли материалы базы знаний и тестовый Telegram-бот для трека 2? | Нужны только при смене трека | Не требуется при треке 1 |
