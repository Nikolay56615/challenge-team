# Офлайн-проверка поиска по словам

Локальный SQLite-каталог содержал 1 086 доступных материалов. На одном каталоге и одной разметке сравнивались персональные рекомендации с отключённым и включённым поиском по словам. Разметка по названиям содержит семь точных, три широких и три запроса без подходящих материалов.

| Группа | Запросов | Hit@3 по правилам | Hit@3 с поиском | NDCG@5 по правилам | NDCG@5 с поиском |
| --- | ---: | ---: | ---: | ---: | ---: |
| Точные | 7 | 3 | 7 | 0,2546 | 0,9894 |
| Широкие | 3 | 1 | 1 | 0,2438 | 0,2438 |
| Все с релевантными материалами | 10 | 4 | 8 | 0,2513 | 0,7657 |

У обоих вариантов 0 ответов со статусом `strong` на трёх запросах без подходящих материалов. Hit@3 считает запросы с оценкой хотя бы 2 в первой тройке. NDCG@5 усредняется по запросам с положительной разметкой. Выборка собрана вокруг проверяемых сценариев и даёт регрессионную оценку для этого каталога.

В разметке `group` принимает значения `exact`, `broad` и `empty`. Поле `task` содержит текст запроса. Поле `grades` сопоставляет идентификаторы материалов с оценками от 1 до 3 и остаётся пустым для `empty`. Разметка реальной выгрузки хранится локально в `data/local/search-relevance.json`.

```powershell
python -X utf8 evaluation/search_relevance.py data/local/alfa-course-details/catalog.sqlite3 data/local/search-relevance.json --signals data/local/alfa-course-details/catalog-signals.sqlite3
```
