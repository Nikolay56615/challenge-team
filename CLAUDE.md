# Работа команды

Начни с [чек-листа передачи](docs/review.md). В нём перечислены файлы, перенесённые из рабочей папки Claude, и проверки для команды. Требования и решения описаны в [плане](PLAN.md). [UI-кит](design/ui-kit.md) задаёт токены, компоненты и состояния. Публичный сайт из [дизайн-референса](docs/design.md) используй для сверки интерфейса.

Команды запуска выполняй из корня. Тестовые профили и каталог входят в код. Локальные копии выгрузки подключай только на чтение по [инструкции](docs/data.md). Храни секреты и данные вне Git и Docker-образа. Используй отдельную ветку для правок и прикладывай к PR результат проверки. Для `Personal/` действуют [правила AGENTS.md](AGENTS.md).
