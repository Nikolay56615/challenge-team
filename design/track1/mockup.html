Макет экрана подбора учебных материалов · трек 1

Локальный макет. Данные вымышленные, оформление нейтральное. Один экран в семи состояниях, каждое в мобильном (390 px) и настольном (1120 px) варианте.

Компоненты и токены зафиксированы в UI-ките: design/ui-kit.md. При расхождении с макетом действует кит.

Спецификация и контракт API — в PLAN.md, раздел «Спецификация интерфейса». Снимок одного кадра: добавьте к адресу ?only=results&device=mobile.

Компоненты и токены

КомпонентЧто делаетДанные из API
TaskFormПоле задачи до 300 символов, кнопка «Подобрать материалы», сброс. Данные не очищаются при загрузке и ошибкеtask
RefinementFieldsТри необязательные группы чипов: стадия, опыт, формат. Одиночный выбор, повторное нажатие снимает выбор. Выпадающий список сферы бизнесаstage, experience, format_pref, industry
DemoPanelТестовый профиль с синтетической историей и переключатель сравнения. Виден только в демо-режимеGET /api/profiles, profile_id
StatusLineСтрока состояния с role="status": загрузка, число найденных, допущения о стадииstatus, message
StateBannerУточнение при слабом совпадении, сообщение об ошибке с кнопкой «Повторить»clarification, ошибка запроса
MaterialCardПозиция, название, бейджи (формат, длительность, платность, уровень, пометка истории), причина, следующий шаг, действия. Переход показывается только при разрешённой ссылке. «Отметить изученным» добавляет событие в историю сеанса и перестраивает выдачуitems[], history
RouteBlockМаршрут из двух–трёх материалов выдачи в порядке изученияroute
EmptyStateСообщение об отсутствии материалов, выбор темы, стартовая подборкаstatus = "none", items стартовой подборки
CompareViewДве колонки на широком экране, вкладки на узком. Один профиль, один каталог, два методаPOST /api/compare

Токены: шрифт системный, базовый размер 15 px, радиус 12 px, сетка 8 px. Цвет не является единственным носителем смысла: платность, ошибка и история дублируются текстом бейджей.
